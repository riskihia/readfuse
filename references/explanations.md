# ReadFuse explanatory notes

Notes help general readers understand difficult concepts or sentences without replacing the author's text. Add them selectively after translation, close to their source-linked paragraph. Usually use 2-4 sentences, with a simple equivalent or paraphrase and one concrete everyday example when useful. No required number of notes per chapter.

Label notes `Catatan ReadFuse — Penjelasan tambahan` for Indonesian editions (or the target-language equivalent). Explicitly identify added examples as ReadFuse examples when there is risk of confusing them with the author's. Do not claim that an invented example occurred in the book.

Preserve the source concept's limits. An analogy must not change causality, overstate evidence, or imply the author's endorsement. If a simple example distorts the idea, use a brief explanation without it. Avoid external factual enrichment and do not present interpretations as author claims.

Store notes in the reviewed JSON format described in architecture.md. Each note anchors to its translated segment. Use short paragraph-level source units for precise proximity. Record a reviewed empty list for clear passages. Notes must be reviewed again if their translation changes.

Do not use a note to silently weaken, correct, or replace the author's claim. Preserve the claim in translation and, if readers need context, label the explanation as ReadFuse's and keep it separate. When translation wording changes, check the affected note again for fit and ensure its added example still illustrates the same concept.
